      SCADA model assumptions & interpretation

      This extension budgets estimated QKD bits into simulated key IDs. It models key pooling, directional use, rotation, expiry, telemetry deadlines, transmission delay, and blocking/recovery. It does not implement AES, a one-time pad, TLS, a real key management system, or physical SCADA interfaces. Message payloads are illustrative labels; nonce counters are bookkeeping, not a security guarantee.

      Authenticated runs assume pre-shared trust and an ideal authentication checker. The MITM scenario flags authentication failure under that assumption. It compromises newly negotiated keys only; existing honest keys remain private until rotation. Without authentication, the model can deliver compromised messages while QBER remains low: matching quantum measurements alone do not establish identity. Abnormal QBER is a disturbance alarm, not proof of eavesdropping. Recovery requires the configured number of consecutive eligible clean rounds; the attack ending does not instantly restore service. Both protocols use instructional QKD key budgets. B92 supports the ideal single-photon IID model; weak-coherent B92 key supply is unsupported.

      Model assumptions & scientific limits+

      This is a reproducible Monte Carlo teaching model. It samples preparations, measurements, loss, detector efficiency, dark counts, and disclosed test bits. QBER is the fraction of disagreements in that test sample; it is not a direct measurement of Eve.

      BB84's final-bit figure is a conservative educational estimate using a finite-sample error bound, reconciliation overhead, and a privacy-amplification penalty. It is not a composable security certificate or an implemented error-correction protocol. No keys are generated for real use.

      B92 uses two nonorthogonal states and conclusive measurements. Its estimated key budget now uses a phase-error operator witness from the standard B92 filtering model, with IID confidence intervals for errors, conclusive events, and loss. This is not a full composable finite-key proof. Weak-coherent-source B92 key estimates remain unsupported. Weak coherent sources and PNS attacks are exploratory; a decoy-state security proof is not implemented.

      Authentication of the classical channel is assumed. Device imperfections, side channels, timing, detector attacks, and real optical hardware are outside this model. Seeded randomness supports reproducibility and is not cryptographically secure.

      Scientific context: Security of quantum key distribution with imperfect devices and B92 over a lossy and noisy channel. These references do not certify this implementation.
